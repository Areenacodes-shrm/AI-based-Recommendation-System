# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within this project, please notify the maintainers privately rather than opening a public issue.

1. Email the project maintainer with the subject `[SECURITY] AI Recommendation System Vulnerability`.
2. Include detailed steps to reproduce the issue, proof-of-concept payloads or code, and any suggested mitigations.
3. Maintainers will review the submission and respond within 48 hours.

Thank you for helping keep this project and its users secure!
